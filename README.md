# HopePath 🌿

HopePath is a personal project I created to offer a small moment of hope in the middle of everyday life.

The idea behind this website is simple: sometimes all we need is a few encouraging words, a short prayer, or a reminder that we are not alone. HopePath brings these elements together in a calm, minimal space without distractions.

## Features

* 🙏 Daily prayers
* 💚 Encouraging reflections
* ✨ "One Small Step" daily motivation
* 📱 Responsive design for desktop and mobile
* ⚡ Fast and lightweight interface

## Built With

* React
* Vite
* Tailwind CSS

## Why I Built It

Over the past few years I've gone through seasons of uncertainty, career changes, and moments where I simply needed encouragement myself.

Building HopePath was my way of combining my passion for web development with something that could genuinely help others, even if it's just for a minute.
