# 🌿 HopePath

HopePath is a gentle web space created to offer hope, encouragement, and peace to people facing uncertainty, stress, burnout, or difficult seasons of life.

Inspired by Christian faith and open to everyone.

## ✨ Features

- 💛 Emotional support based on how you're feeling
- 🙏 Daily prayers and Scripture
- 🌱 Interactive Small Steps
- 📖 Private Hope Journal
- 🔐 Optional Firebase Authentication
- ☁️ Journal and progress sync for registered users
- 💾 Local storage support for guest users
- 🕊️ Peace Corner
- 📚 Helpful resources
- 📱 Responsive design

## 🛠️ Built With

- React
- Vite
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Netlify

## 🔒 Privacy

HopePath can be used without creating an account.

Guest journal entries and Small Steps are stored locally on the user's device. Registered users can securely sync their data through Firebase.

Personal journal content is private and is not shared with other users.
